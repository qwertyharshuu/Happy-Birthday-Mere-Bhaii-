# Hemant Birthday Website 🎂

Open `index.html` in a browser.

Files:
- `index.html`
- `assets/photo1.jpg`
- `assets/photo2.jpg`
- `assets/mera-bhai-tu.mp3`

The website has no music control button. It attempts autoplay on load and also starts the song when the visitor taps the opening "Open Your Surprise" button, because browsers can block audible autoplay until a user interaction.

For GitHub Pages, upload `index.html` and the entire `assets` folder while preserving the folder structure.
